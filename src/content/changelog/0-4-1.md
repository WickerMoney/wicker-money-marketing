Two more categories in the starter set. No database changes, so upgrading is a
pull and a restart, and going back to 0.4.0 is just running the old image.

### Added

- **Memberships.** A new category under Subscriptions, for the store and
  shopping memberships that don't fit streaming or software: Costco, Amazon
  Prime and the like. It's in everyone's starter set.
- **Domains / web hosting.** A new category under Technology, added when you
  tick the setup question about smart home, networking, gaming or web hosting
  (the question now mentions hosting).

Already set up? These aren't added to an existing account on their own. Open
**Categories → Run setup again** and finish the wizard: it adds only what's
missing and leaves every category you already have as it is.
