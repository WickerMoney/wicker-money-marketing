The first tagged release: everything you need to run Wicker Money on your own
server, import your history and see where your money goes. Curated from the
repo's own
[CHANGELOG.md](https://github.com/wickermoney/wicker-money/blob/main/CHANGELOG.md).

### Added

- **Ready to self-host.** A step-by-step quickstart, a published container
  image (amd64 and arm64) that serves the whole app on a single port, and a
  light, dark or system theme.
- **Import and categorization.** CSV import with saved column mapping per
  source, an explicit date format with a live parse preview, duplicate
  detection and batch undo. A categories page with rules — previewed before a
  rule touches anything — and triage on the Transactions page.
- **The shell and the first plugins.** Sign-in, navigation and a dashboard
  fed entirely by plugins. Each plugin gets its own database role, limited to
  the tables it says it needs.
- **Accounts and the ledger.** Accounts, categories, category rules,
  transactions and splits, with every user's data kept apart by the database
  itself. Account balances are worked out from your transactions, never
  stored separately.
- A budgets plugin with per-category budgets, and leftover money that can roll
  over line by line.
- The plugin SDK and UI kit, published to npm, for anyone building a plugin.

### Security

- Closed a hole where one user's transaction could have been attached to
  another user's account.
